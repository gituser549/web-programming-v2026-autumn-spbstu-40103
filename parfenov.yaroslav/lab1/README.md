# Лабораторная работа 1

## Задание

Вариант 13.

Создать блок с текстом произвольной длины. С помощью CSS ограничить его высоту
100 пикселями или тремя строками. Текст, выходящий за установленный предел,
должен обрезаться с многоточием. Шрифт — Arial, размер — 16px.

## Реализация

В `index.html` размещён абзац с длинным текстом, а оформление вынесено в
`styles.css`. Для блока заданы ширина 300px, выравнивание текста по центру и
шрифт Arial размером 16px.

Ограничение текста реализовано сочетанием `display: -webkit-box`,
`-webkit-box-orient: vertical`, `-webkit-line-clamp: 3` и `overflow: hidden`.
Браузер отображает не более трёх строк и добавляет многоточие, если текст не
помещается.

## Запуск

Откройте `parfenov.yaroslav/lab1/index.html` в браузере. Установка зависимостей
и запуск сервера не нужны.

Чтобы проверить ограничение текста, измените длину текста внутри `<p>`: короткий текст
должен отображаться целиком, длинный — занимать не более трёх строк.
