# Лабораторная работа 2

## Задание

Вариант 13.

Реализовать функцию `getZodiacSign(date)`, определяющую знак зодиака по дате
рождения. Функция должна принимать объект `Date` и возвращать русское название
знака с заглавной буквы, например `Скорпион`.

## Реализация

В `solution.js` экспортируются класс `ZodiacSign` и функция
`getZodiacSign(date)`. Результат работы функции — название знака зодиака.

Класс хранит название знака и границы его периода. Статический метод
`getAllZodiacSigns(year)` формирует периоды для заданного года. Функция получает
год из переданной даты и последовательно находит подходящий период, включая обе
его границы.

Период Козерога разделён на два интервала: в начале и в конце года.

## Запуск

Импортируйте `getZodiacSign` из `solution.js` как именованный экспорт ES-модуля.
Например, из корня репозитория выполните:

```bash
node --input-type=module -e "
import {getZodiacSign} from './parfenov.yaroslav/lab2/solution.js';
console.log(getZodiacSign(new Date('2001-10-25')));
"
```

Результат:

```text
Скорпион
```
