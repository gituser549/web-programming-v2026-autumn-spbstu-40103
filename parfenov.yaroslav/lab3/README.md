# Лабораторная работа 3

## Задание

Вариант 13.

Реализовать функцию `sortByFrequency(arr)`, которая упорядочивает элементы
массива по убыванию частоты их появления, группируя одинаковые значения.
Наиболее частые элементы должны располагаться первыми.

## Реализация

В `solution.js` экспортируется функция `sortByFrequency(arr)`. Сначала она
подсчитывает количество вхождений каждого элемента с помощью `Map`, затем
создаёт пары «частота — значение» и сортирует их по частоте.

Сортировка идёт по убыванию частоты: частые элементы располагаются раньше
редких. При одинаковой частоте сохраняется порядок первого появления значений в
исходном массиве.

Результат собирается в новом массиве с помощью `fill`: каждое значение
повторяется столько раз, сколько встретилось в исходном массиве. Исходный массив не
изменяется. Для пустого массива возвращается `[]`.

## Запуск

Импортируйте `sortByFrequency` из `solution.js`. 
Например, из корня репозитория выполните:

```bash
node --input-type=module -e "
import {sortByFrequency} from './parfenov.yaroslav/lab3/solution.js';
console.log(JSON.stringify(sortByFrequency([4, 4, 4, 2, 2, 1])));
"
```

Результат:

```text
[4,4,4,2,2,1]
```
